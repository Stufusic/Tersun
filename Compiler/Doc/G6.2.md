# G6R.2 — VM/JIT PERFORMANCE CONVERGENCE

## Master Implementation Plan

**Trạng thái:** Draft / Implementation Blueprint
**Tiền đề:** G6R.1 đã được VERIFIED & SEALED

# 1. Mục tiêu tổng thể

G6R.2 không phải “thêm optimization”.

G6R.2 là quá trình:

```text
G6R.1 Root Cause
        ↓
Targeted Optimization
        ↓
Micro Validation
        ↓
Full Benchmark
        ↓
Forensic Re-run
        ↓
Differential / Regression
        ↓
Seal
```

Mục tiêu performance ban đầu:

```text
W1 JIT/optimized path:
251.77 ms → ≤ 120.00 ms

W2 Auto/JIT path:
14.93 ms → ≤ 4.50 ms

W3 Baseline JIT:
16.22 ms → ≤ 5.50 ms

W4 Auto/JIT path:
15.33 ms → ≤ 1.80 ms
```

Các target trên là **engineering targets**, không phải pass/fail tuyệt đối nếu việc đạt target gây regression hoặc phá invariants.
